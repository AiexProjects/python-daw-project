A Python-based synthesiser and step sequencer with MIDI and DJ controller support.

## Requirements
- Python 3.11+
- A MIDI device (optional)

## First Time Setup

1. Clone the repo

2. Make the setup script executable and run it\
   `chmod +x setup.sh`\
   `./setup.sh`

3. Activate the virtual environment\
   `source .venv/bin/activate`

## Running the App
- rn do
```bash
cd /Users/alexlee/python-daw-project
python src/laav/main.py
```


- `source .venv/bin/activate` (only if virtual environment is not active)
- `laav`

## Running Tests
- `pytest`
